📱 طريقة تشغيل أداة الحل على موبايلك (Termux)
===================================================

1. انقل الملف المضغوط (اداة_الموقع_termux.zip) لهاتفك (في مجلد Downloads).
2. افتح تطبيق Termux واكتب الأوامر التالية بالترتيب:

# 1. السماح بالوصول لملفات الهاتف:
termux-setup-storage

# 2. تحديث وتثبيت البايثون وأداة فك الضغط:
pkg update -y
pkg install python unzip -y

# 3. الانتقال لمجلد التنزيلات وفك الضغط:
cd /sdcard/Download
unzip اداة_الموقع_termux.zip -d tool
cd tool

# 4. تشغيل الأداة:
bash run.sh
(أو: python server.py)

3. بعد التشغيل، افتح متصفح هاتفك (Google Chrome) وادخل على الرابط:
http://localhost:8700

مبروك! ستفتح معك واجهة الأداة الكاملة على هاتفك ويمكنك وضع الحسابات والحل مباشرة من الموبايل! 🎉
